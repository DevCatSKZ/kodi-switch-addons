# Contributor instructions

- Use English for project documentation, release notes and repository descriptions.
- Preserve upstream license notices and publish corresponding source references.
- Do not commit user profiles, credentials, device addresses or local filesystem paths.
- Publish only reviewed packages for the intended Kodi NX ABI.
- Keep versioned assets immutable. Publish assets before updating the catalog.
- Verify SHA-256 checksums after upload and test installation on target hardware.
- Do not claim complete compatibility from compilation or a library-load test alone.
